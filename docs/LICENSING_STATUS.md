# Licensing status

Repository evidence currently shows no root `LICENSE`, `COPYING`, or `NOTICE` file and no license declaration in `pyproject.toml`.

This is a release blocker for SignPath Foundation eligibility. The project maintainer must select an OSI-approved license, confirm that all source and distributed components can be redistributed under the project’s terms, and publish the license in the repository before applying.

This document deliberately does not select or imply a license on the maintainer’s behalf.
