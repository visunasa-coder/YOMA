# Open-source license selection brief

YOMA currently has no root `LICENSE`, `COPYING`, or `NOTICE` file and no
license declaration in `pyproject.toml`. This document is preparation only; it
does not grant copyright permissions and is not an active project license.

## Candidate

MIT License is a suitable permissive OSI-approved candidate for a Windows
desktop application that is intended to distribute source and compiled
artifacts while allowing reuse and modification. Apache License 2.0 is another
OSI-approved permissive candidate when the maintainer specifically wants its
express patent-license terms.

## Required maintainer decision

The maintainer must choose one license, confirm authority to license all YOMA
source and build scripts, review every bundled or distributed component and
its license obligations, and publish the complete license text at the
repository root. The maintainer must also confirm that optional integrations,
Piper, model files, and other distributed assets are legally redistributable
under the selected project terms or are separately and clearly licensed.

Do not rename this document to `LICENSE` and do not submit YOMA as licensed
until that review and publication are complete.
