# YOMA Enterprise Installer — M55

Run `YOMA-Setup.exe` as Administrator.

The installer:
- installs YOMA into Program Files\YOMA
- installs the YOMA Control Server Windows service
- provisions YOMA models
- launches the standalone first-run setup wizard

The setup wizard supports:
- Organization Administrator
- CEO / Executive
- Manager
- Employee

Google Workspace and attendance integrations remain governed operations.

AI execution authority is never granted by the installer.
Human approval and the existing YOMA governance boundary remain mandatory.
